# 데이터 모델링의 3단계(순서)
1. 개념적 모델링
    - 업무중심적이고 전체적인 관점의 고수준 모델링
    - 핵심 엔터티를 식별하는단계->ERD초안 작성
    - `추상화 수준이 가장 높음`

2. 논리적 모델링
    - 세부속성,식별자,관계 등을 구체적으로 정의하는 단계
    - `정규화를 수행`
        - 정규화: 테이블을 쪼개는 것 (유연성)

3. 물리적 모델링
    - 실제 데이터베이스 구조로 구현하는 단계((EX)CREATE TABLE)
    -  `가장 구체적인 모델링이며. 추상화 수준이 가장 낮음`
